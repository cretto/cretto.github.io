# About

I'm an Engineering Manager and Software Engineer with over 10 years of experience designing, building, and leading the development of scalable software systems.

Throughout my career, I've worked across startups and global enterprise environments, contributing to cloud-native platforms, distributed systems, IoT solutions, and mission-critical applications.

My primary focus is building reliable, maintainable, and scalable software while helping engineering teams grow through technical leadership, mentoring, and continuous improvement.

## Professional Journey

My career started as a Full Stack Software Engineer, where I built web applications and backend services.

Over the years, I expanded my responsibilities to include software architecture, cloud infrastructure, distributed systems, technical leadership, and engineering management.

I've worked on products ranging from IoT platforms processing millions of sensor events to enterprise applications supporting global operations.
